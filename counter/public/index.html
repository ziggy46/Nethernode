NetherNode install counter

NetherNode installs can opt in to being counted. Once a day they send a random install ID, made on their machine, and their version number: nothing else.

This counts how many installs reported in the last 30 days. It stores only the ID, the version, and the day of the last report, forgets an install after 90 days without one, and keeps no request logs or IP addresses.
